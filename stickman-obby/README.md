# Stickman Obby

A small browser-based stickman obstacle-course game.

## Play
Open `index.html` in any modern browser. No installation or build step is required.

## Controls
- Move: **A / D** or **← / →**
- Jump: **W**, **↑**, or **Space**
- Mobile: use the on-screen buttons

## Features
- Platforms and lava hazards
- Checkpoints
- Finish line and win screen
- Restart button
